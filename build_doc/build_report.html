Executive Summary

Illumi (short for IlIlluminate) is a sharp, straightforward, and judgement-free personal financial management (PFM) AI assistant. Designed as an intelligent chat overlay inside a mock smartphone frame, Illumi provides users with conversational, natural-language insights into their historical spending data.

Real-Time Tool Calling

Dynamically evaluates queries to run precise Python functions instead of stuffing thousands of rows into the context window.

Read-Only Guardrails

Strictly focused on analytics, spend tracking, subscriptions, and travel costs. Zero transactional or card management risk.

Mobile Banking UX

Embedded in a responsive smartphone container with integrated brand merchant logos and clean dark-navy styling.

User Stories & Functional Coverage

Illumi successfully satisfies core PFM requirements through structured modular tool execution against enriched statement datasets.

1. Travel Spend Analysis ("How much did my recent trip to Toronto cost?")

Implemented

Tool Invoked: search_transactions(location="Toronto")

Aggregates PRESTO transit fares, Bike Share Toronto rentals, foreign currency conversion fees, and calculates total CAD-to-GBP conversion costs.

2. Recurring Subscriptions ("Can you list my recurring subscriptions and memberships?")

Implemented

Tool Invoked: get_recurring_charges()

Filters transactions with high recurring_confidence, isolating digital tools like Spotify (£3.66) and Google One (£1.59) alongside sports club memberships.

3. Anomaly & Outlier Detection ("Did I have any unusually large expenses in July?")

Implemented

Tool Invoked: analyze_anomalies(month="July")

Detects spike anomalies such as the £1,000 lump-sum card payment to Vanguard, cleanly separating it from the regular £150 monthly direct debit.

Technology Stack & Backend Components

Built using a lightweight, lightning-fast Python and Streamlit ecosystem.

Backend & Agent Runtime

  • • FastAPI: Exposes the /chat REST endpoint with asynchronous execution.
  • • OpenAI SDK (GPT-4o): Direct tool-calling orchestration with schema bindings.
  • • Pydantic: Strict request body typing and response data structuring.
  • • Python Dotenv: Secure local management of OPENAI_API_KEY.

Frontend User Interface

  • • Streamlit: Rapid frontend chat wrapper mimicking mobile viewports.
  • • Custom CSS Viewport: Styled with a dark-navy mobile frame container.
  • • Clearbit Logo Integration: Automatically injects verified brand icons alongside mentioned merchants.

System Architecture & End-to-End Flow

Visualizing how messages travel from the Streamlit smartphone wrapper through FastAPI and the OpenAI tool-execution loop.

END-TO-END SEQUENCE FLOW
[User Prompt]   → [Streamlit Mobile UI (`frontend/app.py`)]   → [FastAPI Endpoint (`backend/main.py`)]   → [OpenAI GPT-4o LLM API]
[LLM Decision]   → Identifies need for tool (e.g., search_transactions(location="Toronto"))   → Executes Python Function via TOOL_MAP   → Injects JSON output back to LLM context
[Final Response]   → Returns natural-language insight to FastAPI   → Streamlit processes response & injects Clearbit brand badges   → Rendered inside smartphone frame UI

Production Hardening & Mobile App Integration

Blueprint for scaling Illumi from a local prototype into an enterprise-grade mobile banking feature.

Security & PII Masking

Implement tokenization and stripping of raw bank account numbers or sensitive personal identifiers before payloads reach third-party LLM inference nodes.

Scalability & Caching

Use Redis-backed caching for frequent category queries and statement aggregates to minimize LLM token latency and operational costs.

Observability & Guardrails

Integrate OpenTelemetry tracing alongside prompt-guard middlewares to monitor token usage, latency anomalies, and prevent prompt injection vulnerabilities.
